# vault module

A KMS vault with one AES-256 master key plus four Vault secrets:

- `<prefix>-mew-password` — generated by Terraform, used as the initial Mew
  Postgres admin password. Rotate after apply.
- `<prefix>-modal-token`, `<prefix>-slack-webhook-url`,
  `<prefix>-pagerduty-integration-key` — placeholder slots created with
  `REPLACE_ME` content. The operator must rotate them before the relevant
  service starts.

The `secret_content` of every slot is `ignore_changes`'d so post-apply
rotations don't get clobbered on the next plan.

## Rotating a placeholder

```bash
oci vault secret update-base64 \
  --secret-id <ocid> \
  --secret-content-content "$(printf 'real-value' | base64)"
```

## Inputs

| Name             | Type          | Required | Description                          |
| ---------------- | ------------- | -------- | ------------------------------------ |
| `compartment_id` | `string`      | yes      | Compartment for vault, key, secrets. |
| `name_prefix`    | `string`      | yes      | Resource name prefix.                |
| `freeform_tags`  | `map(string)` | no       | Tags applied to every resource.      |

## Outputs

`vault_id`, `master_key_id`, `mew_password` (sensitive),
`mew_password_secret_id`, `placeholder_secret_ids`.
